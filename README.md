# 📚 LPI — Linguagem de Programação

Projeto desenvolvido para a disciplina de **Linguagem de Programação I (LPI)**, com o objetivo de aplicar conceitos fundamentais da programação em Java, evoluindo desde exercícios básicos até conceitos de **Programação Orientada a Objetos (POO)**.

## 🎯 Objetivo

O projeto reúne as atividades desenvolvidas durante a disciplina, permitindo praticar conceitos de:

* ☕ Java
* 🧠 Lógica de programação
* 🔀 Estruturas condicionais
* 🔁 Estruturas de repetição
* 📦 Classes e objetos
* 🔒 Encapsulamento
* 🧩 Programação Orientada a Objetos
* 🖥️ Interfaces gráficas com JavaFX
* 📄 FXML e Scene Builder

## 🛠️ Tecnologias utilizadas

* **Java**
* **JavaFX**
* **FXML**
* **Scene Builder**
* **Maven**
* **Git / GitHub**

## ▶️ Como executar

### Pré-requisitos

Antes de executar o projeto, é necessário possuir:

* Java instalado;
* Maven instalado;
* IDE compatível com projetos Java/Maven, como Eclipse ou Spring Tools for Eclipse.

### Execução

Clone o repositório:

```bash
git clone https://github.com/IsraelMCardoso/LPI.git
```

Entre na pasta do projeto:

```bash
cd LPI
```

Compile o projeto:

```bash
mvn clean install
```

Depois, execute o projeto pela IDE ou pelo método de execução configurado no projeto.

## 📖 Atividades

O projeto contém atividades desenvolvidas ao longo da disciplina, começando por exercícios de lógica e evoluindo para conceitos de orientação a objetos.

Entre os conceitos trabalhados estão:

* Entrada e saída de dados;
* Variáveis e tipos de dados;
* Operadores;
* Condicionais;
* Repetições;
* Métodos;
* Classes;
* Objetos;
* Atributos;
* Encapsulamento;
* Organização de código;
* Interfaces gráficas.
